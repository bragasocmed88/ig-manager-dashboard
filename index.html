3. Paste Long-Lived Access Token di bawah ini.

Deploy Gratis via GitHub Web (Tanpa Install Aplikasi)

Kamu bisa meng-online-kan dashboard ini 100% gratis langsung dari browser lewat GitHub Web:

1. Buat Repository Baru: Buka github.com → klik + New repository → beri nama ig-dashboard → pilih Private/Public.

2. Upload File HTML: Klik Add file → Create new file, beri nama index.html, lalu paste seluruh kode ini dan klik Commit changes.

3. Aktifkan GitHub Pages: Masuk ke tab Settings → Pages, pada bagian Branch pilih main lalu klik Save. Dalam 1 menit web kamu sudah online!
